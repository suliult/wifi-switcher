# Wi-Fi Switcher

Windows 本地 Wi-Fi 切换小工具，支持隐藏 Wi-Fi。

## 启动

推荐双击 `Start-WifiSwitcher-Silent.vbs`，不会显示命令行窗口。

也可以双击 `Start-WifiSwitcher.bat`，命令行窗口会最小化。

启动时使用快速加载：只读取 Windows 已保存的 Wi-Fi 配置名称，不扫描周围热点，也不导出完整配置 XML。这样打开更快，但列表刚出现时只表示“已保存”，不代表当前一定可用。

如果需要确认哪些 Wi-Fi 当前可用，点击 `刷新`。刷新会扫描周围 Wi-Fi，并重新按状态分组；保存配置较多或无线环境复杂时，刷新会比启动加载慢。

## 添加隐藏 Wi-Fi

1. 打开工具。
2. 在 `添加隐藏 Wi-Fi` 区域的 `SSID` 输入隐藏 Wi-Fi 名称。
3. 输入 Wi-Fi 密码。
4. 大多数家用/办公路由器保持 `安全类型 = WPA2PSK`、`加密方式 = AES` 即可。
5. 点击 `添加/更新`。
6. 在列表里选中这个 Wi-Fi，点击 `连接`。

密码会通过 Windows 自带的 `netsh wlan add profile` 写入系统 WLAN 配置。这个工具不会另外保存密码文件。

## 切换 Wi-Fi

启动后列表先显示 `已保存 Wi-Fi`。点击 `刷新` 后，列表会按状态分组：

- `可用的已保存 Wi-Fi`：当前扫描到，并且已经保存过密码/配置。
- `隐藏/未确认的已保存 Wi-Fi`：保存配置里标记为隐藏网络，Windows 扫描时无法确认具体 SSID。
- `暂未扫描到的已保存 Wi-Fi`：已经保存过，但当前没有扫描到。

选中具体 Wi-Fi 配置后点击 `连接`，也可以直接双击列表项。分组标题不能连接。

连接操作会立即向 Windows 发送连接请求，工具会在后台确认连接结果；成功后不会自动完整刷新列表，避免额外扫描导致卡顿。

## 删除已保存 Wi-Fi

选中已保存的 Wi-Fi 配置后点击 `删除配置`，确认后会从 Windows 系统 WLAN 配置中删除。

## 注意

- 如果隐藏 Wi-Fi 是 WPA3 Personal，选择 `WPA3SAE`。
- 启动列表是快速加载结果；要查看当前可用状态，请点击 `刷新`。
- 如果连接失败，优先确认 SSID 拼写、密码、安全类型是否正确。
- 如果提示 Wi-Fi 当前不可用，通常表示这个热点不在范围内，或者隐藏 Wi-Fi 还没有被 Windows 扫描到。
- 部分公司管控电脑可能禁止普通用户新增 WLAN profile，需要管理员或策略权限。
